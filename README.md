# Task Management API

API для управления задачами, категориями и комментариями. Реализовано на Django REST Framework.

## Функционал

- CRUD для категорий, задач, комментариев
- Массовое создание, обновление и удаление (batch delete через параметр `ids`)
- Пагинация (10 записей на страницу, настраивается через `?page=2`)
- Троттлинг: 100 запросов/час для анонимов, 1000 запросов/час для авторизованных
- JWT-аутентификация
- Автоматическая документация Swagger UI
- Кеширование GET-запросов (15 минут)
- Фильтрация списков по полям

## Эндпоинты

### Категории (`/api/v1/categories/`)

| Метод | URL | Описание |
|-------|-----|-----------|
| GET | `/api/v1/categories/` | Список категорий (фильтр `?name=`) |
| POST | `/api/v1/categories/` | Создать одну или несколько категорий |
| GET | `/api/v1/categories/{id}/` | Получить категорию по id |
| PUT | `/api/v1/categories/{id}/` | Полное обновление категории |
| PATCH | `/api/v1/categories/{id}/` | Частичное обновление категории |
| DELETE | `/api/v1/categories/{id}/` | Удалить категорию |
| DELETE | `/api/v1/categories/batch/?ids=1,2,3` | Массовое удаление категорий |
